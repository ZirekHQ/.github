# Support

Thanks for using ZirekHQ projects. Here is how to find help, ask questions, or report issues.

## Documentation

Start with the project documentation:
- Organization docs: [zirekhq.github.io](https://zirekhq.github.io/)
- Each repository's `README.md` for project-specific setup and guides

## Asking Questions

Ask in [GitHub Discussions](https://github.com/ZirekHQ/ZirekHQ.github.io/discussions). It works in the browser, it's searchable, and you don't need to join a
mailing list. Pick the category that fits:
- **Q&A:** questions about installing or using a tool, or about contributing.
- **Pronunciation:** a Kurmanji word, number or abbreviation that sounds wrong. Write the exact text and how it
  should sound.
- **Translation:** questions about translating the NVDA add-on or the apps.
- **Voices:** the voices, recording your own voice, and voice quality.
- **Ideas:** suggestions that aren't ready to be an issue yet.

You can write in Kurmanji or English.

## Reporting Bugs or Requesting Features

- Use the repository's **Issues** tab and select the appropriate template (**Bug report** or **Feature request**).
- For bug reports, include reproduction steps, version/commit SHA, and actual vs. expected behavior.

## Security Vulnerabilities

Please do not report security vulnerabilities in public issues. Refer to [SECURITY.md](SECURITY.md) for instructions on submitting private vulnerability reports.
