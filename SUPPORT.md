# Support

Thanks for using ZirekHQ projects. Here is how to find help, ask questions, or report issues.

## Documentation

Start with the project documentation:
- Organization docs: [zirekhq.github.io](https://zirekhq.github.io/)
- Each repository's `README.md` for project-specific setup and guides

## Asking Questions

If you have questions about using a tool or library, or want advice on contributing:
- Open an issue on the relevant repository if GitHub Discussions is not enabled.
- If you aren't sure which repository is relevant, open an issue in [ZirekHQ/.github](https://github.com/ZirekHQ/.github/issues).

## Reporting Bugs or Requesting Features

- Use the repository's **Issues** tab and select the appropriate template (**Bug report** or **Feature request**).
- For bug reports, include reproduction steps, version/commit SHA, and actual vs. expected behavior.

## Security Vulnerabilities

Please do not report security vulnerabilities in public issues. Refer to [SECURITY.md](SECURITY.md) for instructions on submitting private vulnerability reports.
