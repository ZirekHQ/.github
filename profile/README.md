## Zirek

Kurdish language technology — work towards software that can read and speak
Kurdish.

### Projects

- **[nvdaku](https://github.com/austek/nvdaku)** — Kurdish (Kurmanji) localisation
  for the [NVDA](https://www.nvaccess.org/) screen reader: interface translation,
  character descriptions and symbol dictionaries.
- **Kurmanji text-to-speech** — training neural voices for Kurmanji, and
  contributing Kurdish phoneme support upstream to
  [espeak-ng](https://github.com/espeak-ng/espeak-ng).

### Help wanted

Kurmanji is poorly served by assistive technology, and most of what is missing
needs native speakers rather than programmers:

- **Reviewing the NVDA interface translation** — it is partial and dated.
- **Character descriptions and symbol names** — judgement calls that a
  non-daily speaker should not be making alone.
- **Voice recordings** for text-to-speech training.

If you'd like to help with any of these, open an issue on the relevant
repository. Kurmanji, Sorani and Zazaki speakers all welcome — the current work
is Kurmanji-first only because that is where it started.
