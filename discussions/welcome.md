# Bi xêr hatî! · Welcome!

**Kurmancî**

Ev der cihê pirs û nîqaşan e ji bo projeyên Zirek û dengê kurmancî Dengjen. Tu ne hewce ye ku kod binivîsî da ku alîkariyê bikî.

- **Q&A:** pirsên li ser sazkirin û bikaranînê.
- **Pronunciation (Bilêvkirin):** peyveke ku xelet tê gotin? Nivîsa rast û awayê rast binivîse.
- **Translation (Werger):** wergerandina pêveka NVDA û sepanan.
- **Voices (Deng):** deng, tomarkirina dengê xwe û kalîteya dengan.
- **Ideas (Raman):** pêşniyarên nû.

Tu dikarî bi kurmancî an bi îngilîzî binivîsî. Ji kerema xwe re rêzê li hev bigire.

**English**

This is the place for questions and discussion about the Zirek projects and the Dengjen Kurmanji voice. You don't need to write code to help.

- **Q&A:** questions about installing and using the tools.
- **Pronunciation:** a word that sounds wrong? Write the exact text and how it should sound.
- **Translation:** translating the NVDA add-on and the apps.
- **Voices:** the voices, recording your own voice, and voice quality.
- **Ideas:** new suggestions.

Write in Kurmanji or English, and please be kind to each other. Bugs still go to the issues of the relevant repository; security reports follow [SECURITY.md](https://github.com/ZirekHQ/.github/blob/main/SECURITY.md).
